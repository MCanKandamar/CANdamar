# CANdamar.exe (Windows)

A single-file Windows build of CANdamar. It starts the CANdamar server in the
background and shows the UI in its own window (Microsoft Edge WebView2), so
the target PC needs neither Python nor Node.js.

## Requirements on the target PC

- Windows 10 or 11
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
  (already installed on Windows 11 and on most Windows 10 PCs)

## Using it

Double-click `CANdamar.exe`, pick the interface (for example **slcan** and your
adapter's COM port) and click **Connect**. Closing the window stops the server
and releases the COM port.

If the window cannot show the app (WebView2 missing or broken), CANdamar opens
in your default web browser instead and tells you so; closing the CANdamar
window still stops it.

Data is kept in `%LOCALAPPDATA%\CANdamar`:

| Path | Content |
|------|---------|
| `candamar.log` | Server log -- check here if the app does not start |
| `logs\` | Recordings (`.asc`, `.csv`) |
| `replay\` | Files uploaded for replay |
| `webview\` | Window storage (saved layout, custom plot signals) |

Command-line options: `CANdamar.exe --port 47800` (local server port),
`--no-window` (server only, open `http://127.0.0.1:47800` in a browser),
`--debug` (WebView developer tools). Set `CANDAMAR_DATA_DIR` to keep the data
next to the exe instead (portable use).

## Building

```powershell
powershell -ExecutionPolicy Bypass -File packaging\windows\build_exe.ps1
```

Needs Python 3.10-3.13 and Node.js 20+. The script builds the frontend,
creates `build\exe-venv` with `candamar[desktop]` and PyInstaller, and writes
`dist\CANdamar.exe`. Use `-Python C:\path\to\python.exe` to pick the
interpreter.

The `Windows exe` GitHub Actions workflow runs the same script on every `v*`
tag, smoke-tests the exe and attaches it to the GitHub release.

| File | Purpose |
|------|---------|
| `build_exe.ps1` | Build script |
| `candamar.spec` | PyInstaller spec (hidden imports, data files, icon) |
| `candamar_desktop.py` | Entry script, calls `canviz.desktop.main()` |
| `candamar.ico` | App icon, generated by `make_icon.py` |
